# Katalog

Vue製のコンポーネントカタログツール

## 概要

StorybookはReact製でReactのサポートが手厚いため、Vue開発者にとって最適とは言えません。Katalogは、Vue開発者のためのコンポーネントカタログツールとして開発されています。

## 目標

- Vue 3に最適化されたコンポーネントカタログ
- TypeScriptファーストサポート
- 直感的で使いやすいUI/UX
- 高速な開発体験

## 技術スタック

- Vue 3 + Composition API
- TypeScript
- Vite
- Vitest

## 開発

```bash
# 依存関係のインストール
pnpm install

# 開発サーバー起動
pnpm dev

# ビルド
pnpm build

# テスト実行
pnpm test

# 型チェック
pnpm typecheck
```
